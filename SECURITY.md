# Sicherheitsrichtlinie

## Unterstützte Versionen

NotECAS befindet sich vor Version 1.0. Sicherheitskorrekturen werden nur für den aktuellen Stand auf `main` und die neueste veröffentlichte Vorabversion bereitgestellt.

## Sicherheitsproblem vertraulich melden

Bitte keine Schwachstellen mit möglichem Datenverlust, manipulierten Importdateien oder offengelegten Verbrauchsdaten als öffentliches Issue einstellen.

Meldungen an: **service@moh-computer.de**

Bitte angeben:

- betroffene Version und Android-Version
- nachvollziehbare Schritte oder einen minimalen Testfall
- mögliche Auswirkungen
- vorgeschlagene Abhilfe, falls vorhanden

Keine echten privaten Verbrauchsdaten senden. Benötigte Beispieldaten vorher anonymisieren.

Eine Eingangsbestätigung wird nach Möglichkeit innerhalb von sieben Tagen gegeben. Es besteht kein Anspruch auf eine bestimmte Reaktions- oder Behebungsfrist.

## Geltungsbereich

Besonders relevant sind:

- Datenverlust oder unbemerkte Datenverfälschung
- Import manipulierter SQLite- oder CSV-Dateien
- Pfad-, Datei- oder Berechtigungsprobleme
- unbeabsichtigte Datenübertragung
- Schwachstellen in Release-Artefakten oder der Build-Pipeline
